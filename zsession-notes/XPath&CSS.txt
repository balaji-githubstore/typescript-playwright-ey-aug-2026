XPath - XML Path Language

Absolute XPath (not recommended) - /html/body/div[1]/div/div/section[1]/div/div/div[2]/div/form/fieldset/div[1]/div/input

Relative XPath - 
//tagname[@attribute='']
//tagname[text()='']

normalize-space() - check text by removing whitespace before & after text 
//tagname[normalize-space()='']


Contains
//tagname[contains(@attribute,'')]
//tagname[contains(text(),'')]
